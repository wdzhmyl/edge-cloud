# 使用手册

本文档介绍智慧工地安全巡检平台各功能的使用方法。

## 一、图片巡检
对单张图片进行 AI 检测，并生成巡检报告。

1. 在左侧上传区**点击或拖拽**图片到上传框（支持常见图片格式）。
2. 点击「**开始巡检**」。
3. 右侧展示结果：
   - 左图为**标注图**：检测到的目标用框标出，闯入危险作业区的目标会**标红**。
   - 右图为**巡检报告**：由云端大模型生成，含「图中人物及数量 / 安全危险情况 / 总结」三段。
4. 巡检成功后，图片会自动保存到「**AI巡检**」相册，可随时前往相册查看。
5. 报告在服务端**后台生成**，通常几秒内完成；若较慢，可先离开页面，结果仍会保存，之后在相册查看。

> 提示：关闭生成中的页面/弹窗**不会中断**后台推理，报告生成后会自动保存到数据库。

## 二、实时监控
调用摄像头进行实时逐帧检测与危险区预警。

1. **选择摄像头**：
   - 本机摄像头：点击「搜索摄像头」自动发现并选择；
   - 手机摄像头：安装 IP 摄像头 App（如 IP Webcam / DroidCam），将地址（如 `http://手机IP:8080/video`）粘贴进输入框，点「添加」后选择。
2. 点击「**开启监控**」开始逐帧检测。
3. 监控开启后**切换到其他页面不会中断**，只有手动点「停止监控」才结束。
4. **划定危险区域**：点击「划定危险区域」，在画面上按住拖拽框选，可划多个；区域按用户保存，右侧列表可单独删除。
5. **截屏存证**：检测到闯入时每 5 秒最多自动截屏一次，也可随时「主动截屏」；截图自动存入相册（仅保留最新 4 张）。

## 三、相册
管理巡检图片与监控截图。

1. 监控截图自动收入默认相册；图片巡检结果存入「AI巡检」相册。
2. 支持**新建文件夹**进行多级分类整理。
3. 「多选」后可**批量移动 / 删除**。
4. **再次巡检**：鼠标悬浮到某张图片，点巡检按钮即可对已有图片重新检测并生成报告。
5. **共享**：可将文件夹共享给其他登录用户（对方可见，不可修改）。
6. 已巡检的图片会显示「已巡检」标记，悬浮可查看标注图与报告。

## 四、巡检报告说明
报告为纯文本，分三段：

- **一、图中人物及数量**：列出检测到的作业人员、工程车辆等目标及数量。
- **二、安全危险情况**：是否存在人员闯入危险作业区、车辆违规、防护缺失等，并给出风险等级（低 / 中 / 高）。
- **三、总结**：一句话概括当前安全状态与需关注重点。

## 五、危险作业区
推荐**手动划定**：在实时监控页点「划定危险区域」，在画面上拖拽框选即可，支持多个区域、按用户保存。
默认区域可在后端 `config/settings.py` 的 `DANGER_ZONE` 中调整，或设 `ENABLE_DANGER_ZONE=False` 关闭。

## 六、云端大模型配置（可选）
将 `.env.example` 复制为 `.env`，填入以下项后**重启后端**即可启用云端智能研判：

- `LLM_BASE_URL`：云端接口地址（OpenAI 兼容）
- `LLM_API_KEY`：接口密钥
- `LLM_MODEL`：模型名

未配置时自动使用本地兜底报告，不影响检测功能。

## 七、识别能力
边缘端可识别：作业人员、非机动车、摩托车、通勤车辆、通勤班车、工程运输车、现场信号灯、消防栓、警示标识等，并对危险作业区闯入做实时预警。

## 八、账号与角色
- 登录后点右上角头像可进入「个人中心」，修改昵称 / 头像 / 密码。
- 角色分普通用户与管理员；管理员可在个人中心管理用户权限。

## 九、常见问题（FAQ）
- **Q：关闭生成中的页面，报告还会生成吗？**
  会。报告在服务端后台生成，关闭页面不影响，结果自动保存，之后在相册查看即可。
- **Q：报告生成要多久？**
  与云端模型有关，通常几秒；较慢时请耐心等待，或稍后在相册查看。
- **Q：刷新或重新登录后，巡检结果还在吗？**
  在。结果已持久化到数据库，刷新 / 重登不丢失。
